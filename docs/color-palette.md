# Acuan warna FoodWastey

Sumber terverifikasi: `static/css/base.css` pada main commit 490fd63. Referensi pengguna: https://www.figma.com/design/wSGPDUl78i7Bzpfz7zeWil/FoodWastey?node-id=17-3

Referensi Figma belum dapat diverifikasi melalui koneksi Figma yang tersedia karena akses ditolak. Angka di bawah diambil dari CSS yang sudah dipakai proyek, bukan hasil ekstraksi Figma.

| Token CSS | Warna | Penggunaan saat ini / acuan berikutnya |
| --- | --- | --- |
| `--paper` | `#FDECD8` | Latar halaman krem hangat |
| `--ink` | `#6D3510` | Teks utama cokelat |
| `--accent-dark` | `#597828` | Navbar/footer hijau zaitun; acuan tombol utama |
| `--accent-dark-deep` | `#435A1E` | Bar footer gelap; acuan hover tombol |
| `--accent-dark-active` | `#283612` | Teks navigasi aktif |
| `--accent-light` | `#EEF2EA` | Teks di atas latar hijau |
| `--accent-light-active` | `#CCD5BC` | Latar menu aktif dan teks sekunder footer |

Gaya saat ini memakai Lilita One untuk merek/judul dan DM Sans untuk teks. Halaman pengantar masih memakai warna inline `#2E7D32` untuk judul dan `#555555` untuk deskripsi, di luar token utama. Pada tahap desain selanjutnya, utamakan token CSS yang ada supaya login/register konsisten dengan navbar dan footer. Hindari menetapkan palet baru terpisah; cek kontras teks, border input, dan indikator fokus saat desain formulir dibuat.

Tahap logic registrasi/login belum menambahkan desain formulir final atau mengubah palet aplikasi.
